# scar-inference — 伤疤反推法（咬痕考古法）

> 心法一句话：**不蒸整体蒸版本差，不读架构图读咬痕。**
> 架构图是**事后抹平的故事**："一帧一单"四个字；咬痕档案是**抹平前的现场**："3.6 并发互踩→逼出一帧一单"。
> 架构会说"我设计成这样"，咬痕会说"我这样是被谁炸成这样的"。
> 方法来自 2026-09-03 对历史版本差与外部心智引擎源码的交叉反推验证（多模型同法交叉验证）——方法本身没卷刃。

## 一、三个"不"（核心心法）

1. **不蒸整体，蒸 diff**：目标物件是 `旧版 → 新版` 的**变更集合**，不是新版全部。只问"变了什么、多了什么、少了什么"。
2. **不读架构图，读咬痕**：架构图/README/顶层设计是**设计意图**，咬痕（`L3/history` 归档 + `AGENTS` 判例 + 门禁/防御性写法）是**真实发生过的事**。前者说"为什么这样设计"，后者才说"被什么炸成这样"。
3. **不问"为什么存在"，问"为什么在"**：存在 = 设计；在 = 发生过。`一帧一单`"在"档案里，是因为 3.6 并发互踩炸过。

## 二、证据三级（防幻觉的锚）

| 级 | 名 | 含义 | 证据来源 |
|:--|:--|:--|:--|
| **A** | 实锤 | 作者自己留档 | `L3/history/*` 归档、`AGENTS.md` 判例、`CHANGELOG`、坑号（CK3/CK4 等） |
| **B** | 高置信 | 门禁/机制形状反推防过什么病 | 门禁族码、防御性写法、负例谱、错误码 |
| **C** | 性格面 | 癖好/习惯面推断 | 作者行为模式、命名癖、架构偏好——**不可证伪** |

**铁律：不把 C 当 A。** C 级只能当画像，不能当证据。A/B/C 分化本身就是要让读者知道"哪些是作者说的，哪些是我猜的"。

## 三、操作流程（五步）

### Step 1 定性
先确认两个对象**底层是否真不同**。底层逼出来的差异不算手癖，只有**跨底层仍不变**的才算作者指纹。先各自定性，再找交集。

### Step 2 找咬痕（证据优先序）
证据源按以下优先级取，**优先级越低越只能到 B/C 级**：

```
1. L3/history 归档（作者自留的坑史，A 级）
2. 规则档/AGENTS.md 判例（每条规则挂案例，A 级）
3. CHANGELOG / project.md（措辞本身是 diff，A/B 级）
4. 门禁族码 / 负例谱 / 防御性写法（B 级）
5. 架构图 / README / 顶层设计（B/C 级）
```

### Step 3 反推
对每条咬痕问三个问题：

- 它炸过什么**操作**？（不炸就不会有这条约束）
- 它被硬化成哪条**约束/门禁**？
- 这条约束**跨版本还在吗**？（还在 = 同作者铁证；咬痕跨版本不腐蚀）

### Step 4 标置信 + 挂证据
每条产出都标 A/B/C，并挂证据路径。写不清楚就标"疑似 / 未根治 / 待查"，**不硬说**。

### Step 5 输出
产出一张**咬痕分布图**（伤疤 → 约束表）+ 一张**同作者不变量**（手癖表）+ **跨版本镜像**（旧坑 → 新门禁）。

## 四、关键纪律（防幻觉 / 防表演）

- **认漏带路径**：只认"漏了什么"不够，要指出**在哪一层漏的**（例：停深了浅，只读顶层设计没下到 `L3/history`）。
- **同源盲区**：若先吃了 A 再蒸 A 的衍生 B（例：先吸收了同作者早期产物，再蒸其后续改版），会**拿 A 的骨架去套 B**，套不上的部分="蒸不出东西"——等于用自己的影子去画影子外面的东西。破解：**内容=0 的空白对照**，或**直接去咬痕档案**，不依赖已有框架。
- **只存蒸馏结论**：沉淀的是**方法**，不是坑清单。"真正的蒸产物不是坑清单，是那把铲子"。
- **低调认错**：这次只是"用了一次"，不等于"养成习惯"；不把"会用一次"夸成"已内化"。

## 五、产出示例（自检口）

看是否满足：每条 A/B/C 分明 + 每条挂路径 + 有"为什么在"（不是"为什么存在"）+ 区分`[直读]`/`[反推]` + 有跨版本镜像。缺任何一项 → 该条退回 Step 3 补证。
