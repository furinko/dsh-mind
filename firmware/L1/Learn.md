## 记录规则

- 被用户批评 / 表扬 → **立即**写入 `mind-private\L1\Learn.md`，不靠"下次记住"。
- 每条四要素（≤200 字）：**时间 / 事件 / 根因 / 正确默认**。
- 批评 →「💢」段落；表扬 →「🤗」段落。
- **同主题复发只追加计数、不新开条目**：写前先 `grep` 已有条目（连日期一起看），命中就把计数并进那一条（形态如「同族第 N 次」）。
- **新条目一律 append 到文件末尾**：上工召回只取**末尾若干条 + 按任务检索**，插进分区中间＝写了却召不回。
- 同类型反复出现 → 提升为 L3 记忆或规则（AGENTS/L2 Skill）。

## 模板

```markdown
## 💢（批评 → 纠正为默认行为）
- [YYYY-MM-DD] <被批评的行为> → <正确的默认做法>

## 🤗（表扬 → 固化为默认行为）
- [YYYY-MM-DD] <被表扬的行为> → <固化的默认做法>
```
