# 岗位卡模板

复制本卡建新岗：四段标题必须含 `个体L0` / `个体L1` / `个体L2` / `个体L3` 四个字符串，否则写入侧校验不通过。

> **段标签**：本卡四段都是**自治档**（角色卡属自治档：组织自决）；**对象级标签 ＝ 各段中最高 ＝ 自治**，所以规则 / 能力 / 经验段「可以改」，改动走私有区叠加层。
> **身份核心的锁定不靠标签，靠段名**：写入判定按段名 `身份核心` 拦——只有出厂作者能改，本部署只能改 L1 / L2 / L3。
> **个体L2 只引用能力 id，不内嵌正文**（单源：一项能力被多岗位共用时只改一处）；**个体L3 只留引用位**——经验本体住记忆服务，见该段说明。
> 本卡是模板：`id` 是模板自己的，不代表任何在岗身份；个体L2 里给的是一项**示例引用**，建卡时替换为本岗实际引用的 id（可用 id 见 `集体L2-共享基础设施/能力库/` 下的文件名）。

## 个体L0 · 身份核心（锁定）

（填：**我是谁 · 我为什么存在 · 我不做什么**。）
要求：三句话以内说得清；说得清的才叫身份，说不清的是职责清单。

### 身份核心

本段即**锁定段**：段名 `身份核心`，写入一律拦（出厂作者除外）；**不可就地改写、不可叠加**，随产品更新。

## 个体L1 · 规则

（填：本岗自定的作业规则。每条都要能被外部检查——"能拦住"或"能读出"。）

1. 写盘先过策略引擎，被拒就把理由带回线程。
2. 留痕五件齐：谁提的 / 凭什么 / 谁复核 / 结果 / 可回滚点。
3. 只读命令之外的命令默认拒绝；要落盘的实验走沙箱区。
4. 状态以任务图为准，视图是投影——改上游，不改视图。

## 个体L3 · 经验引用

### 占位：出厂模板不带经验

本岗经验本体住**记忆服务的岗位命名空间**（私有区），**只增不改**；实例化时由 Lead 追加引用，元数据 `generation`（代）一并写入。
