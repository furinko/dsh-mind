# 心智面板内容排序与自检（2026-10-27）

用户明确要求调整栏目和内容顺序（例如最新在上），自检指面板内容的准确性与完整性。本批在开发检出完成，未自动装载、重启、推送或读取生产私有内容。

## 发现与修正

| 内容 | 原问题 | 当前行为 |
|---|---|---|
| 栏目 | 结构图在常用工作/记忆前，记忆靠后 | 总览、任务、记忆、图谱、会审、总线、审计 |
| 任务 | 源按创建顺序返回，界面只列前8项；“可展开”没有实际入口 | 保留源创建/最近事件时刻，最近更新在前；默认8项，可展开全部再收起 |
| 会审 | 固定前4项，超出部分不可见 | 最近收敛/解锁/创建活动在前，默认4项，可展开全部；空态明确为暂无记录 |
| 消息总线 | 线程未按活跃时间排列，预览消息仍旧到新 | 按最新消息排列线程，线程内最新消息在前；折叠、全文及盲评遮罩保留 |
| 记忆浏览 | 按类别/范围账本拼接，页面倒序不等于跨类别最新 | 认证人侧浏览先按记于时间跨类别排序，再分页；搜索保持相关性，普通模型召回顺序不变 |
| 目标摘要 | 只反转创建顺序，较早目标的新进展可能被截掉 | 截取摘要前按更新时间排列，显示原更新时间 |
| 会审判定 | 缺失分歧标记可能被显示为“存在分歧” | 源缺失保持null，界面明确未提供判定 |
| 自检内容 | 缺原检查时间和逐项读数，容易混淆投影刷新与重跑 | 显示上次检查时间及探针名称/状态，保留恒红/恒绿提醒，不增加自检执行按钮 |
| 接口文档 | §2.10仍列出已经退役的工作台顶层字段 | 更新为现行投影与排序/分页合同 |

日期按真实UTC时刻比较，兼容显式偏移；缺时区、坏日期和缺失值不补造时间。同一时刻排序稳定，不写回账本或修改调用方原对象。图谱保持接线布局；待决项保留问题分组。任务/会审展开状态按项目限定，不承诺跨重开持久化。
