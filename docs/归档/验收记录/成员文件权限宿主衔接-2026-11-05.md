## 实现

- 内核只从宿主 `agents.get(parentId)` 取得当前父 Agent，再通过该 Agent 的真实 Cordis 上下文解析 `sandboxPolicy.resolve({session})`。不接受模型参数、权限文字、当前工作目录或单次提权作为授权来源。
- 未配置静态 `memberFileAccess` 时使用这个可信上限；显式配置只取交集，显式空配置仍拒绝。没有真实服务仍拒绝，不自动降级为全盘。
- `read-only` 禁止写委派；`workspace-write` 只授服务返回的工作区范围，不继承环境临时目录例外；`danger-full-access` 仍须 Lead 明确选择冻结任务根。
- 普通成员每次原生文件访问和交付捕获重新检查父策略、绑定凭证与原有组织策略；父失联、未知策略、读期间替换均拒绝。收窄上限不清除重叠活动任务的暂停/禁止工具限制。
- 组织私有/出厂根、链接约束与未知执行器拒绝保留；另拒绝成员写当前 Mind 模块根和 Node 执行目录。并非所有其他插件的安装保护表，Lead 仍不得派发未获授权的运行环境修改。
- 复核员继续沿用独立 task_attach 读根、当前资格与只读工具闭名单，不接入普通成员的写许可；未更改复核/会审的读域模型。

原生宿主沙箱仍独立检查子会话的实际权限。桥不是 OS 文件锁，不能消除外部进程在路径核验之后换链接的竞态。
