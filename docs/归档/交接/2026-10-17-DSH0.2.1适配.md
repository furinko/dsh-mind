# 2026-10-17 · DSH 0.2.1-rc.1 升级后的 dsh-mind 适配

> 交接对象：下一位接手 dsh-mind / 本机 DSH Desktop 的 Lead。
> 结论先给：**宿主 API 对 0.2.1-rc.1 无需改动**（host 半区与浏览器半区均实测兼容）；
> 掉线原因是**部署层的装载清单丢了**，已修好并活体验收。**Team 策略文本锚点换代**
> （`[mind-delegation-v2]`）是同一轮上游文本变化带来的代码改动，落在未提交的模型路由批，
> 不属于 host API 适配。

---

## 一、症状（真机）

DSH Desktop 升级到 **0.2.1-rc.1** 后：

- 本会话的模型工具面里**没有** `mind` / `mind_guard`；系统提示词里也没有组织段；
- `/plugins/dsh-mind/ping` 等四条同源路由 **404**；
- 但 profile 的 `dependencies` 里 `dsh-mind` 还在，插件文件也都在；
- 没有任何宿主报错——**插件一行代码都没跑，却安静得像没事**。

## 二、根因（已取证）

**DSH 0.2.1 改变了装载语义**：`dsh-app-boot` 的 `readBundlePatches` **只遍历
`package.json` 的 `dsh.profile.bundles` 清单**去应用 `dsh.bundle.patch`；
旧运行时还会顺带应用「普通 dependency」声明的 bundle patch。

本机 profile（`%USERPROFILE%\.dsh\profiles\desktop\package.json`）在升级/迁移后，
`dsh.profile.bundles` 里没有 `dsh-mind`（`dependencies` 里仍有 `link:../../plugins/dsh-mind`）。
证据链：

- 升级前的清单备份（`.install-backups/20261017-codex-2.7.1/package.json`，16:33）同样没有
  `dsh-mind`，但 16:24 前插件一直在跑 ⇒ 旧运行时确实是「按依赖自动装」；
- 16:24 重启进 0.2.1 之后，同一份清单下 mind 工具面消失，而 `dshome-plugin`（在 bundles 里）正常；
- 隔离实例里把 `dsh-mind` 加进 `dsh.profile.bundles` 后，cold boot（新进程）下
  `mind` / `mind_guard` 工具与组织提示段全部就位。

> 顺带确认：升级后的 0.2.1 客户端槽位与契约仍在（`main` keyed / `sidebar.panellist` /
> `settings.section`，`tools.register/guard`、`systemPrompt.section`、`webServer.register`、
> `tools/result`·`turn/end`·`session/event` 事件名全部沿用），所以插件代码无需适配改写。

## 三、修复（已落地）

唯一改动：`profiles/desktop/package.json` 的 `dsh.profile.bundles` 末尾追加 `"dsh-mind"`。

- 备份：`profiles/desktop/.install-backups/package.json.pre-mind-adapt-20261017-172051`；
- 该 profile 开着 HMR ⇒ 改动触发 **profile 热重组**，插件在运行中的 App 里立刻装载，
  **本次未重启 App**；未开 HMR 的环境则重启后生效；
- 规范做法仍是插件管理器「插件」页打开开关（会自己追加清单）；手工只许补这一项，别动别行。

回滚：删掉 `bundles` 里的 `"dsh-mind"`（或拷回上面的备份）→ 热重组/重启即回到未装载态。

   `[mind-delegation-v2]`；`mind_guard probe_run` 四道探针全绿。

   页面轮询计数持续增长（读请求真实到达）。
3. **冷启动（新进程）验证**：用同一份 profile 组合在隔离 DSH_HOME 里 cold boot
   （`dsh` CLI，非本机 App），注入一次性探针读宿主真实注册表：
   `toolNames` 含 `mind`、`mind_guard`，`ctx.systemPrompt.assemble()` 含组织段；
   装载告警里**没有** dsh-mind（其余告警是隔离实例缺 installAnchor 的解析差异，与本插件无关）。
   ⇒ **下次 App 重启不会复现掉线**。
4. **浏览器半区（无头 Edge + CDP，0.2.1-rc.1 真实 UI）**：模块 factory 注册、boot graph
   含 `dsh-mind` 行、0 未捕获异常（有正对照证明捕获通道会红）、侧边栏「心智 · 数字组织」入口、
   设置页「心智」分区（真实读数 + 346 条 CSS 规则）、看板真实数据（审计/能力卡/岗位接线）、
   四条同源 fetch 全 200。六项全 PASS，无 0.2.1 不兼容项。截图见
   `_mind_adapt_shot/`（工作区证据目录）。
5. **门禁**：`node scripts/verify-profile-install.mjs <profile>` 全绿（含「bundles 含卡」判据）、
   `--selftest` 10/10、`node test/preflight.mjs` exit 0；全量测试套件结果见交付回执。
