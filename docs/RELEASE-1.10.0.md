# dsh-mind 1.10.0 发布候选

心智为DSH增加可追溯的任务协作、对话延续、记忆和工作台。普通对话直接进行；需要正式交付时，再使用任务、成员、独立复核与Lead采纳。

## 首版能力

- 目标与任务：验收判据、精确任务绑定、成员派发、成果引用、独立复核、采纳及结账。
- 对话与记忆：轮级原文缓冲、按话题跨会话召回、项目工作摘要、长期记忆搜索和来源续读、更正及停用。
- 自主复核：Lead冻结本任务的代码、命令和预算，复核员独立复跑并读取原始输出；沿用宿主权限与原有审批要求。
- 工作台：岗位能力图谱及悬浮详情、任务、会审、消息总线、记忆和审计历史。建岗模板保留在工厂区，不作为用户岗位展示。
- 设置：核心人设、运行与审批、成员调度及信息来源。保存后独立回读，冲突保留草稿，未知回执不伪装成功。
- 慢读处理：同一会话与项目的在途工作台读取合并；超时取消底层请求，并保留最近已知快照与明确错误，恢复后继续读取。
- Windows文件兼容：来源根统一真实路径拼写，盘符大小写按本机路径语义核对；文件身份、私有目录排除和链接拒绝仍独立检查。文件替换遇短暂占用时有限退避，保留旧文件并在持续失败时明确报错。

## 安装与兼容

一个包、一张插件卡，包含内核、安全类和看板三个组件。以DSH `0.2.1-rc.2`为宿主验收基准；Node要求`^22.19.0 || >=24.0.0`。宿主仍在预览阶段，不推定其他宿主版本兼容。

在目标profile中通过DSH插件管理安装发布包；命令行可使用`dsh plugin --profile <名> add <包或本地tarball路径>`。核对profile的`dependencies`和`dsh.profile.bundles`包含`dsh-mind`后，在空闲时重启目标DSH；运行`node scripts/verify-profile-install.mjs <profile绝对路径>`核对包与组件形状。升级前保留私有数据备份，按已支持的数据布局核对回退版本；回退源码不等于回滚数据。

## 已知边界

- Mind不提供OS沙箱，不包装宿主执行权限；完全权限shell仍可修改工作区外文件。任务文件授权不会自动限制其他宿主工具。
- 自动协作记忆默认关闭；检索、装配和采用声明不证明理解、收益或长期成长。轮缓冲仍受保留期限和容量上限约束。
- 完整目标费用预算、统一跨进程恢复和知识质量闭环尚未完成。
- 四项安全探针只说明各项机械检查的结果；长期“恒绿”仍按既有诊断规则提示，不认证一般安全性。
