## 新增配置与历史行为

- `memberFileAccess`：宿主内核配置的 `read` / `write` 绝对根数组；缺省空集，成员不自动获得通用文件权限。配置形状或路径非法（含组织双区等非法根）时降级为只读自述。它是 mind 的可授上限，不能宣称代表宿主未公开的全部权限。
- `工具文件范围`：`task_dispatch` / `member_spawn` 的可选参数，只有 Lead 可在部署者上限内授予。省略则不授文件域；派发后冻结。`member_spawn` 在宿主创建之前先核验；任务交卷关闭通用文件窗口。shell/未知执行类没有新增授权入口。
- `projectBindings`：宿主可信配置的 `{path, project}` 数组，缺省空。新目录使用路径派生键；发现未认领同名历史账时拒绝。一个真实目录对应一个项目键，不自动合并、移动或拆分旧账；既有按项目键配置的调度授权需在真实部署迁移时核对。
- 旧任务没有文件域或绑定凭证时不自动补权。新绑定由服务钉岗位、实例代、卡摘要及宿主代次，逐次与现身份核对；同岗原凭证正规 restore 保留正例，换岗/新代/新卡不能继承。旧交卷没有内容清单时不新出合格票，不借旧票、免审或历史确认补造采纳证据；另立节点交新卷。已完成的合法历史采纳/结账保留历史事实。

## 独立审查后的修复

第一轮 1123 项绿测之后，独立攻击夹具确认三项 P1 与一项 P2；四项修复后的 1139 项绿测之后，最终核对再补首道闸不可注册时的装载错误信号。1123 与 1139 均保留为对应补修前的阶段记录，不能当作最终验收。

1. **硬链接别名**：realpath 不识别同 inode 的多个目录项。现对普通文件强制 nlink=1，覆盖原生文件目标、递归搜索、复核/会审资料域、文件树和对象证据捕获与重验；目录不按此文件规则误拒。真实 fs.link 将私有 identity.json 和外部普通文件链接进授权根，均有拒绝反例。
2. **通用工具绕过现行策略冻结**：同步闸逐次核对成功加载时使用的全部授权原文，完全一致才复用现有策略本体；依赖改变、重载中或不健康立即拒绝。不复制一套撤回/失联规则，也不依赖过期 mtime。真实本人/父 Lead/节点 revoke、实时失联、审批/工具范围动态收紧、同尺寸恢复 mtime、配置故障与恢复均有正反例。交付物捕获同样复核当前资格。
3. **坏配置提前返回造成零 guard**：承重范围闸在第一次 await 前同步注册，初始化失败仅保留 mind status 自述（空 action 仅兼容同一自述），原生工具、组织写动作与无身份未知工具均拒绝；合法初始化后才接通真实判定。无法确认父归属的故障阶段不开放报告通道。
4. **同 id 换岗继承旧任务文件权**：新绑定保存真实实例凭证，文件工具和捕获持续比对岗位、实例代、卡摘要及宿主代次；旧凭证不补造。真实 seal→换岗、换回原岗但新代/新卡/新宿主代次均拒绝；同岗原凭证 seal→restore 仍允许。
5. **首道闸注册失败却正常返回**：首道 `tools.guard` 注册抛错或接口缺失时，保留 error 日志并抛稳定 `Fault`（`KERNEL_REQUIRED_GUARD_UNAVAILABLE`），原 cause 保留；不注册 degradedTool、命令、提示词或钩子。已有承重闸后的坏配置仍保持有闸自述降级。这里只确认 Mind 组件加载失败，不声称宿主所有原生工具已停止；整机停止工具依赖宿主将这项安全依赖设为必需并执行其装载策略。

独立 reviewer 以自己的攻击夹具复验前四项，第五项由主代理与 reviewer 的独立夹具共同确认后完成最小补修。随后冻结源码运行下面的最终完整测试池。
