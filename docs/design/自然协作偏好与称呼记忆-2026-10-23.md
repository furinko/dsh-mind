# 自然协作偏好与称呼记忆

2026-10-23调整：核心人格改由[本地私有卡](本地主权核心人设-2026-10-23.md)维护；本自动提炼链路默认关闭，只有显式 `自动协作记忆: true` 才启用。当前QQ群桥未提供可信发送者/群来源，不启用自动长期固化。以下描述保留已有实现合同，不表示当前部署默认开放，也不能用于改写核心卡。

用户自然表达的称呼、角色形象、语言和交流/协作习惯，由同一宿主模型路由在轮末异步提炼，写入现有私有偏好账本，沿用Lead连续性召回、策略判定及记忆生命周期。没有固定名字、关键词改名规则或固定回复模板。内部Lead岗位与实例名继续承担权限和协作职责，不限定对外称呼；角色约定不改变真实模型、能力和权限。

`ContinuityCaptureService`复用项目接续的来源登记、字节预算、并发检查及处理水位，独立保存每项目提炼位置。首次启用会从该项目已登记的轮缓冲来源补读，不要求用户重复旧会话原话。最多16个来源会话、每批24条消息、每次任务两批、输入36000 UTF-8字节、最多12个主题。模型无工具、20秒超时，来源及当前身份变化时拒绝旧结果；未显式启用`自动协作记忆`或关闭`轮级缓冲`均停止自动链路。辅助调用仍未计入现有agent用量账本。

模型输出区分人格/用户偏好、部署/项目范围、有效/停止。每个新增、更正或停止项须引用本批已接纳用户消息，并逐来源给出精确原文片段。助手回复只供理解上下文，不能作用户决定的证据；截断、中断或时间未知的来源不能晋升。普通问答、临时扮演、引用示例、任务要求、秘密和无关个人事实不应进入协作偏好；这些语义判断由模型完成，来源校验不等于语义认证。

正式记忆记录保存有界原文片段、来源项目/会话/事件/消息id、时间及内容哈希。自动主题更正以稳定主题归一，模型改变主题标签时，可按输入提供的同类同范围正式记忆id认回；新条目与旧条目推翻/停用在同一账本锁、同一次追加中提交。更正不继承旧偏好作为证据。不同来源项目写同一部署主题时也在正式账本锁内核对先后，旧历史不能覆盖新用户表达。来源键幂等，使正式记忆已提交而处理位置未保存时可重试，不重复产生条目。

人侧invalidate/demote/overturn/purge会保留不含原文的主题哈希、幂等键及毫秒时间屏障；补读旧来源及同批重试不能恢复已停用或删除的偏好，真正后续新表达可重新约定。停止操作留下不召回的墓碑。正式记忆可继续用`memory_query`查看、`memory_lifecycle`更正、停用或按原规则删除。轮缓冲清空不删除已经形成的正式记忆；正式条目的有界来源片段随原条目一同受物理删除处理。

新会话使用现有`mind:lead-continuity`带入正式记忆。辅助提炼尚未结束时，`mind:pending-continuity`只带最新有界用户原文，不回放旧提炼草稿，已失效正式偏好不能从草稿复活。装配顺序在轮缓冲同步及待整理表达之后读取正式连续性，避免首次装配错过刚完成的持久化。对话直接沿用约定，不向用户输出记忆机制说明。

自动采集不保证一般语义准确率，也没有代替所有长期记忆管理。稳定专业知识和协作教训仍走原记录/采纳流程。程序回归与真实模型验收分别记录于[当前状态](../STATUS.md)。
