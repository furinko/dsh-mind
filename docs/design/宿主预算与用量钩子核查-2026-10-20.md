## 3 next 必须显式透传

事件实现：`C:/Users/kuro/.dsh/profiles/node_modules/@deepseek-ai/cordis/lib/index.js:308–324`。

waterfall 按注册顺序从外层调用，末尾默认行为作为 innermost next；一个监听器不调用 next，就截断余链。实现直接返回当前回调返回值，**undefined 不会自动继续**。371–379 的 `ctx.on` 只绑定并登记回调，没有把普通观察者转换成自动透传中间件。

`ctx.on` 的 reflect.bind 在同文件 917–920 对回调参数走 trace；84–89 的 getTraceable 仅包装带内部 tracker 的服务值。普通 ToolExecution 无该 tracker，仍是原对象；此绑定既不会自动调用 next，也不会给 undefined 补默认 allow。

观测钩子须显式透传：

```js
ctx.on('tools/pre-execute', (exec, next) => {
  beginSafely(exec);
  return next();
});
```

本次检查发现仓内旧 `components/kernel/lib/observability-hooks.js` 曾以 `exec => { begin(exec); }` 注册 pre，未透传 next。按本安装实现会令 gate 为 undefined，随后读取 gate.kind 抛错；原假宿主按 emit 触发 pre 的夹具不能发现这一问题。本轮已修为显式返回 next，夹具改为 await pre waterfall 后才执行同步 guard；原业务断言保留并补充了透传反例。不能把这些隔离绿测试描述为真实运行验证。

预算中间件可在下游正常返回后预占，保留下游原决定：

```js
ctx.on('tools/pre-execute', async (exec, next) => {
  const decision = await next();
  if (decision.kind !== 'allow' && decision.kind !== 'ask') return decision;
  const admission = await reserveCoveredAttempt(exec);
  credentials.set(exec, admission); // 仅在持久预占及所需审计成功后发布
  return decision;
});
```

`await next()` 抛出的原错误应直接透传；不要把下游拒绝或错误伪装成预算失败，更不能返回 allow。ask 在本中间件之后才发生真实审批，所以也预占；审批拒绝、取消及后 guard 拒绝保留计数、不自动退款。若外层监听器跳过预算钩子或把 deny 改为 allow，最终同步 guard 因缺少本服务签发的当前凭据而拒绝。

## 4 调用身份、参数与归因

工具类型 `lib/types/index.d.ts:197–220` 给出 callId、name、arguments、真实 caller agent、parent token、signal；261–265 加入 rootCallId 和本次 token。源码 3027、3487–3488 每次生成独立 Symbol；3016–3019、3108–3127、3192、3211–3213、3293 持续传递同一 execution 对象。因此服务私有 `WeakMap(exec)` 可串联 pre、guard 和 result，不能仅凭可重复 callId 认回。

参数正文经 3055–3059 snapshot 与 deepFreeze；但 execution 是普通对象，直到 3285 才整体冻结。公共类型规定身份 readonly，execute 包装器仅能替换 signal；实现未在 pre 前把 name、agent、arguments 属性设为不可写。因此 guard 仍应核验当前工具名、参数摘要、真实项目、成员凭证和目标归属，拒绝 pre 后漂移。guard 之后的其他宿主插件须遵守其公共包装器合同，本轮不声称隔离违反合同的插件代码。

PTC 子调用在 1211–1219 构造独立 callId，传入真实 agent、rootCallId 和父 token；1272–1294 逐次经过同一 prepare/dispatch/finalize。父调用凭据不能自动复用给子调用。

归属只能来自当前真实成员绑定和同一目标，或服务器已准备的明确任务宏调用。多个目标不应选一个少扣；Lead 的未归因原生调用、模型自报任务/目标、来源字符串均不能伪装可证明归属。额度只增加限制，不授予任何原任务或工具权限。
