# 持久目标、当前约束与任务关联

日期：2026-10-20。本文描述开发候选的实际合同，完整结果见[第四轮验收](../第四轮修复验收-2026-10-20.md)。目标负责保存期望结果、约束、决定及任务引用；任务图继续拥有任务状态、冻结判据、署名和采纳事实。

## 来源与决定

`goal_create` 接受 Lead 对明确用户意图的登记，不为同一意图增加确认。`来源` 是调用者转述，持久记录为 `来源声明.用户意图=未核验`；文字、链接或参数不能变成真人认证或权限凭据。本轮没有接入可核验的用户消息来源。

Lead 通过 `goal_revise` 可以增加文本约束和精确禁止工具，不能改写期望结果、完成依据或删除已有约束。人侧命令 `goal_decide` 可以变更意图、限制，或暂停、取消、恢复暂停；它不在模型工具枚举中。入口从可信 command 面构造人侧主体后才准备计划，工具参数中的 `面`、角色或认证声明不能取得该资格。来源转述仍不伪装成已核验原始用户消息，人侧决定的实际主体单独留在事件中。

保存目标与人侧决定不会授予新的文件范围、宿主权限或后台执行资格。

## 接口与修订

| 动作 | 必要输入与结果 |
|---|---|
| `goal_create` | 期望结果、完成依据数组、来源、下一步；可给约束、禁止工具和请求键 |
| `goal_query` | 有 id 读当前详情，无 id 读分页摘要；仅真实在岗 Lead 或主权者 |
| `goal_revise` | id、当前修订、来源及要修改的字段；Lead 仅增加限制 |
| `goal_progress` | id、当前修订、进行中或等待；等待须给具体等待原因，进行中保有下一步 |
| `goal_link_task` | id、当前修订、同项目真实任务 id；只存关联，不复制任务状态 |
| `goal_complete` | id、当前修订、说明、证据任务数组、逐条完成核对 |
| `/mind goal_decide` | 人侧明确给状态决定，或目标修订字段；两种操作不能混合 |

事件存放在项目任务目录的独立 `goals.jsonl`。修订从 1 连续增长，内容、进展、状态、关联和完成均占新修订。写入带预期修订，陈旧写明确冲突，不覆盖他人进展。

同主体、项目、规范请求创建得到稳定 id。给请求键时同键不同规范拒绝；相同创建重试只读认回真实当前进度，不重置状态、不追加业务或伪补审计。它不是跨主体的用户意图去重；新会话应先查询现有目标。其它写入不能用旧修订重放。

目标计划由领域服务签发，审批预览与执行消费同一份冻结输入、事件及源摘要。读计划在锁内不能转写；当前资格、修订、证据或计划变化时重新准备。业务事件已落线而审计失败，回执保留目标 id、项目和事件序号，不能当作未执行。

严格读取拒绝坏 JSON、撕裂末行、未知字段和事件、无效状态、非连续修订、跨目标重复关联；不能跳行生成较早约束。账本目前不证明合法行删除或整本回滚未发生。

## 目标状态与任务关系

`进行中`、`等待` 是 Lead 对合法下一步的进展记录；等待条件解除后可以继续推进，不增加人侧确认。`暂停` 必须由人侧恢复。`取消` 和 `已完成` 为只读终态，新工作另建目标，保留旧成果引用。

单个任务只关联一个目标，不能解绑或换目标洗掉限制。正式后继沿不可变的前序关系继承同一目标的当前约束；建立关系不需要在两本账里各写一笔。子任务先关联、之后关联父任务时也核整个前序关系，拒绝跨目标冲突或缺失、成环的链。

新派发、开工、创建正式后继在目标锁内检查当前目标为进行中。`member_spawn` 在准备、审批和首次宿主创建之前检查当前状态，已暂停目标不能先创建执行实例再等派发失败。暂停前已经进入宿主创建的操作仍可能完成，部分提交按实际阶段记录，不能声称世界原子停止。

目标写与任务事件按目标锁、任务锁的统一顺序串行。暂停先落线，后来的新推进拒绝；派发先落线，事实保留，随后暂停阻止新开工。已发生的交卷、复核、采纳、结账和组织终止可以收尾记录，不能借此恢复目标或改写旧判据。

## 机器约束的覆盖

机器禁止工具只接受 `read`、`read_image`、`glob`、`grep`、`write`、`edit` 的精确数组。自由文本约束提供上下文，由执行者判断；本轮不把自然语言当成完整可执行规则。

成员原生文件调用逐次读取真实当前目标。对本人精确绑定、仍活动、凭证和范围仍有效、命中本路径的任务，目标限制取交集；不能筛掉受限任务后借另一条重叠无目标授权通过。非进行中的目标阻止新文件写，明确禁止工具同时限制对应读取。递归搜索还要检查其目录树将触及的窄任务根；反向包含只增加限制，不授予父目录读取权限。不相交的独立任务输出范围仍可使用。

这不是整个项目或目标成果路径的永久保护：宿主没有可信的本次任务归因；Lead 原生工具调用、无关联任务及其它工具未获得目标级覆盖。终止或采纳后的旧任务根退出活动授权候选，独立现行授权是否仍可操作同一路径按实际范围判断。不能用自报任务或文本猜测填补该缺口，也不把历史根永久锁死。

检查发生在工具进入前，不能撤销已获许可的在途 I/O。暂停、取消或完成不证明宿主已停止、外部副作用回滚或恰好一次执行。

## 完成与跨会话读面

`完成核对` 是 `[{依据,任务:[id]}]`：精确覆盖每条当前完成依据，引用不得超出证据清单，证据清单每项也须被核对引用。服务从本项目任务真源检查关联和合法采纳，并重新核验交付物清单的当前内容；旧采纳之后产物已变，不能直接用来完成目标。

机器核引用、资格、当前版本和内容。完成仍标为有实际证据支持的主体判断，`机器证明目标语义=false`，不按任务数、结账数或全部终态自动完成。

新装配从同一账本重建目标、当前限制、历史决定和任务关系。查询列表默认 20、最多 50 项，并给总数、偏移与 hasMore；显式详情保留完整当前约束，历史及关联窗口带截断计数。工作台默认最多 10 个摘要，任务进展从当前任务图重算，标明摘要省略并指向详情。成员暂不取得整个目标读域，工作台目标栏为 null；目标账本故障显示不可用和未知，不冒充零目标。

本轮未增加后台调度、自动接管、共享预算、跨项目目标搜索或全局宿主硬停。后续依赖见[路线图](../ROADMAP.md)。
