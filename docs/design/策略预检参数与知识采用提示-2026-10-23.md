# 策略预检参数与知识采用提示

日期：2026-10-23。承接[首批专业知识对照](../归档/验收记录/专业知识效用对照-2026-10-23.md)暴露的错误预检停顿及采用自述冲突。

`policy_check`只预检调用者所给对象标签与真实任务上下文。它不发文件路径许可；实际操作仍过原业务策略和原生工具文件范围闸。受管工具内部的执行前判定已经属于“先判定”，不必为每次文件调用构造额外许可证。

`target`必须为JSON对象，含非空字符串`kind`。`authority`复用现有授权标签清单：宪章、法律、自治、只增；任务id与主体岗位不属于此字段。`zone`来源区接受出厂、私有及策略已有的合并、旧数据，工作目录或workspace不是来源区。省略标签沿用原来的自治、私有默认；已知真实标签必须如实填写。显式非法标签、null、坏JSON、裸路径和非对象结构先报`INVALID_BODY`，不进入策略或任务读取，也不把参数错误报告成需要更高授权。

任务内预检仍通过顶层`任务`寻址服务端真实任务。缺项不自动补本人活动任务；读写判定、负责人、状态、当前身份、跨项目及复核员边界仍由原策略决定。成员非read预检漏任务时，在原判定之外提示缺项；真正的deny/confirm不因纠错说明变为allow。只可纠正与真实对象不符的输入，不能降低已知有效标签、换对象或去掉限制求放行。未识别对象类型沿用原策略语义，不新增对象权限规则。

专业自动段明确是当前活动绑定的快照。交卷后绑定不再活动而段变空，不证明此前没有召回。`采用知识`可基于此前实际见过的自动摘要或显式查询全文和实际使用来声明；仅看到不代表采用，不确定使用结果保留未知，未用保持显式空数组。来源版本哈希核对版本，不认证实际采用或收益。

`task_submit`成功响应增加固定`知识采用说明`，提醒Lead通过原`knowledge_reuse_query`核对原始声明；后续口头更正不覆盖原交卷，不重交洗账。没有增加采用记录、曝光台账、权限、历史读面或自动训练；任务与记忆账本合同不变。提示只能改善可理解性，模型是否遵循、质量与成本是否改善仍须新案例验证，不能回填旧失败。
