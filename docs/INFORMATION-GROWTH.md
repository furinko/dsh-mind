# 信息来源、会话分享与 Lead 成长

2026-10-24：通用本地收录与有来源的成长流程。目标是让 Lead 延续兴趣、幽默、审美、好奇与独立判断，形成有趣、可爱的个性；不预设撒娇、卖萌或每次交谈必须产生教训。持久资料不等于模型参数训练，也不证明主观感受或长期人格效果。

## 三种入口，一套流程

- **会话是人的主入口**：分享链接、文字，或说“这个记一下”。Lead 引用当前宿主已接纳消息的真实 ID 收录。链接不代表已抓正文，附件引用不等于附件内容；普通问答不必归档。轮末辅助阅读可选择有意义的相遇，无收获时不保存整段对话。
- **目录是持续来源**：在“心智设置 → 见闻与成长 → 选择信息来源目录”像选择工作区一样浏览文件夹，勾选多个目录后一次连接。跨层级保留选择、标明已连接目录；桌面原生选择器可连续添加后一次保存。默认跨项目、仅Lead、包含子目录，连接后可分别编辑用途和范围；手填路径保留为备用。目录适用于知识库、插件导出和字幕。支持 UTF-8 Markdown、TXT、JSON、JSONL、HTML/HTM、VTT/SRT；HTML仅抽取文字，不执行网页。PDF、Office、图片、音视频需外部插件先转换，当前不声称理解这些二进制格式。
- **插件交接**：已认证固定端点接收结构化文字；Lead也可使用原插件的读取工具，将正式结果回执接入。没有任意命令、工具名或URL转发器。

收录 → 版本快照 → 分页阅读 → 兴趣/认识/共同回忆/表达趣味/疑问/知识或能力候选 → 召回与试用。缓存、阅读、反思、试用与掌握分别记录；没有收获可以只完成阅读。

## 来源与生命周期

来源登记名称、路径、子目录开关、扩展名、用途（探索/专业/两者）和范围。原目录只读；索引、快照、回执和收获保存到私有目录 `信息收录/`。用途是阅读提示，不构成权限。

默认每60秒扫描一批，轮末阅读前也尝试扫描。目录之间轮转，目录内持久保存位置，重启可接续；默认每批150项。隐藏项、node_modules、链接和过深目录跳过，Mind私有区、出厂区及其祖先不能作为来源。错误和超限不算学习完成，扫描不完整时不把未访问文件算作删除。

材料ID绑定来源和相对位置，正文按内容指纹快照。文件修改留旧版本，新版使旧派生认识退出自动使用。来源关闭、断开、缺失后停止自动使用其派生认识，人侧仍可核对历史。撤回阻止自动重收录；删除快照清理派生收获和未被其他资料共用的快照，保留无正文的撤回标记。原文件、宿主对话与备份分别管理。

## 会话、关系与范围

会话收录从轮缓冲取得实际消息ID、角色、序号、指纹和截断标记。助手内容不认证成用户表达，当前只覆盖轮缓冲已有文字。默认各会话关系独立；人侧可把明确属于同一人的会话关联到稳定关系标识，不根据昵称或自报身份合并。

目录可设项目/跨项目、仅Lead/共享给指定岗位。普通成员还需在岗凭证和当前活动任务；会审与复核继续走既有读域。提炼只取来源范围交集；组织分享需人侧明确创建共享副本，私有原件保留。资料不改变宿主权限、身份或核心人设。

## 自动阅读与成本

默认开启目录增量收录及轮末辅助阅读，使用当前真实Lead的模型路由。每轮末最多两批，每个UTC日默认最多4次、提供来源文字48000字符；每批最多12000字符和3条收获。调用前持久预留，失败不退还；计量为来源字符与辅助调用准入次数，不是token、总费用或整个会话硬限额。

辅助模型没有工具、权限或宿主系统提示，只输出结构受限JSON。引文必须位于实际提供的片段，程序核对出处、版本与覆盖，不认证语义正确。长文按覆盖区间续读，片段反思不能声称完整观看。

没有模型路由时保持待阅读。恢复会话尚未完成本进程的 Lead 身份接续时只等待，不占阅读预算、不记模型失败，也不由后台阅读自行续接或恢复身份；正常宿主会话入口核验后再安排阅读。组件停止、会话/项目变化、暂停、配置变化或来源撤回后，旧辅助结果不能提交，在途模型尝试取消。重启不自动重放未知调用。状态区分阅读中、完成、失败及部分覆盖。

## 成长与能力

成长保留引文、回执、来源版本、范围、修订与可选到期时间。兴趣可淡去，也可用新材料重新理解；显式替代使旧记录退出默认使用并保留历史。人侧纠正或停止的记录，模型不能自行覆盖或恢复。

能力候选保留方法、适用条件、局限与岗位，阶段为灵感/待试用/已验证/需修订。标“已验证”需同项目真实已采纳或已结账任务的一次有帮助试用声明，仅证明关联与状态可核对，不证明能力导致改善或可以泛化；无改善、变差和未知同样保留。

来源有效、完成试用且明确跨项目共享给岗位的候选才能发布自治能力库。发布使用稳定ID，支持核对重试，不覆盖其他内容；发布后仍检查来源与候选有效性，撤回或推翻后退出Mind默认能力列表、解析与读取。已进入模型上下文的内容不因此被声称抹除，外部代码不因入库就安装执行。

## 模型动作

三个动作属于原有 `mind` 工具，身份与项目来自真实会话：

- `information_query`：`信息={collection:"status|materials|growth|interests|candidates",id?,query?,offset?,limit?}`。
- `information_read`：`信息={id,hash?,version?,offset?,limit?}`；返回readingId、文字、覆盖和nextOffset。计入阅读预算，不自动产生反思。
- `information_update`：`信息={op,data}`。submit：`{messageIds,title?,note?}`；submit_tool：`{receiptId,title,note?}`；record：`{type,kind?,title,text,sources:[{readingId,quote}],method?,conditions?,limitations?,roles?,expiresAt?,replaces?:[{id,revision}]}`；finish：`{readingIds}`；revise：`{id,revision,reason,text?,state?,stage?,trial?:{task,outcome,detail},expiresAt?}`；publish：`{id,revision}`。

模型不能配置来源、预算、关系或分享范围。新版本需要重新阅读，旧引用不自动升级。

来源工具回执只观察宿主 `tools/result` 正式成功文字，用服务端随机ID绑定实例/会话/项目，内存最多64项、30分钟有效，卸载清空。当前适配 `bili_humanism_read/source/inbox/personality`、`bilibili_subtitles/video`、`bilibiliextract`、`rss_fetch`、`read`、`web_fetch`、`web_search`。不替换任何宿主或第三方方法。文字最多12000字符，仍保留分页、摘要或片段限制。

## 已认证人侧与插件API

三个固定端点都要求宿主Connection认证和同源，缺认证不退回无头通道：

| 端点 | 合同 |
| --- | --- |
| `/plugins/dsh-mind/information` | GET：配置、来源、分页资料/成长/候选、用量和任务；POST：configure/source_save/sources_add/source_remove/scan/revise/forget/purge/share/relationship |
| `/plugins/dsh-mind/information-material` | GET：id/hash/version/offset/limit查看原文；人侧预览不消耗模型阅读预算 |
| `/plugins/dsh-mind/information-deposit` | POST：producer、externalId、title、text、coverage、scope，可附author/url；不主动访问URL |

配置修改带expectedRevision=configRevision，记录修改带revision，旧草稿返回409。投递ID绑定producer、externalId和范围，同文幂等、新文留版。HTTP体最多64KiB，大材料走目录；单文件默认最多1MiB。scope为 `{project:null或项目键,audience:"lead|roles",roles:[],relationship:null或稳定标识}`；共享岗位必须明确给出。

`sources_add`接收`{op:"sources_add",expectedRevision,sources:[来源配置,...]}`，一次新增1至64个来源，不接受已有id。全部路径、范围、重复与容量校验通过后才原子保存；任何一项失败不部分连接。目录选择只使用宿主公开的`uiWorkspace.listDirectory/pickDirectory`与桌面窄选择接口，不创建工作区或会话，也不修改宿主服务。

账号评论、私信、点赞等不属于本功能；第三方插件的账号开关与调度仍归其自身。本功能不以收录数、反思数或模型自评证明人格成长与任务收益。

目录发现兼顾现有兴趣的标题词面线索与陌生领域探索，不把词面匹配称为语义理解。全文搜索每批最多检查200份资料，按nextOffset续查，明确已检查范围与命中数。相同规范化快照只在同范围内复用整理状态。readChars按UTF-16代码单元计数。
