# 信息来源、会话分享与 Lead 成长

2026-10-24：通用本地收录与有来源的成长流程。目标是让 Lead 延续兴趣、幽默、审美、好奇与独立判断，形成有趣、可爱的个性；不预设撒娇、卖萌或每次交谈必须产生教训。持久资料不等于模型参数训练，也不证明主观感受或长期人格效果。

## 三种入口，一套流程

- **会话是人的主入口**：分享链接、文字，或说“这个记一下”。Lead 引用当前宿主已接纳消息的真实 ID 收录。链接不代表已抓正文，附件引用不等于附件内容；普通问答不必归档。轮末辅助阅读可选择有意义的相遇，无收获时不保存整段对话。
- **目录是持续来源**：在“心智设置 → 见闻与成长 → 管理信息来源 → 连接目录”像选择工作区一样浏览文件夹，勾选多个目录后一次连接。跨层级保留选择、标明已连接目录；桌面原生选择器可连续添加后一次保存。默认跨项目、Lead自治吸收与分配、包含子目录；可勾选“私密来源（仅Lead）”或限制项目。手填路径保留为备用。目录适用于知识库、插件导出和字幕。支持 UTF-8 Markdown、TXT、JSON、JSONL、HTML/HTM、VTT/SRT；HTML仅抽取文字，不执行网页。PDF、Office、图片、音视频需外部插件先转换，当前不声称理解这些二进制格式。
- **插件交接**：已认证固定端点接收结构化文字；Lead也可使用原插件的读取工具，将正式结果回执接入。没有任意命令、工具名或URL转发器。

收录 → 版本快照 → 分页阅读 → 兴趣/认识/共同回忆/表达趣味/疑问/知识或能力候选 → 召回与试用。缓存、阅读、反思、试用与掌握分别记录；没有收获可以只完成阅读。

## 来源与生命周期

来源登记名称、路径、子目录开关、扩展名、用途（探索/专业/两者）和私密边界。原目录只读；索引、快照、阅读回执及尚未提交的草稿保存到私有目录 `信息收录/`。正式正文保存在原记忆账本；完成后的收录回执只留原生记忆ID、出处、覆盖、范围、处理位置与历史元数据。用途是阅读提示，不构成权限。

默认每60秒扫描一批，轮末阅读前也尝试扫描。目录之间轮转，目录内持久保存位置，重启可接续；默认每批150项。隐藏项、node_modules、链接和过深目录跳过，Mind私有区、出厂区及其祖先不能作为来源。错误和超限不算学习完成，扫描不完整时不把未访问文件算作删除。

材料ID绑定来源和相对位置，正文按内容指纹快照。文件修改留旧版本，新版使旧派生认识退出自动使用。来源关闭、断开、缺失后停止自动使用其派生认识，人侧仍可核对历史。撤回阻止自动重收录；删除快照清理派生收获和未被其他资料共用的快照，保留无正文的撤回标记。原文件、宿主对话与备份分别管理。

## 会话、关系与范围

会话收录从轮缓冲取得实际消息ID、角色、序号、指纹和截断标记。助手内容不认证成用户表达，当前只覆盖轮缓冲已有文字。默认各会话关系独立；人侧可把明确属于同一人的会话关联到稳定关系标识，不根据昵称或自报身份合并。

目录可设项目/跨项目、Lead自治或仅Lead。自治来源由Lead按实际岗位分配专业知识；人侧不逐条指定知识该归谁。旧版本显式设置的岗位名单继续作为上限，私密或关系资料不能由模型扩散。普通成员还需在岗凭证和当前活动任务；会审与复核继续走既有读域。提炼只取来源范围交集；私人资料若要组织分享，需人侧明确创建共享副本，私有原件保留。

数据所有者是持续的Lead，而非一次运行实例。自身人格自省可部署级延续；用户偏好、共同经历、原生个人记忆及项目摘要沿同一份显式关系绑定隔离。不根据昵称合并人际关系。轮级缓冲仍按真实根会话和项目存放，项目摘要可存多组关系的条目但只能读取当前关联组；清空一组不清空另一组，后来登记的旧历史也受清空时间屏障限制。缓冲到期或清空不会删除已经正式保留的经历，删除正式资料应使用对应记忆或来源的忘记入口。

不为目录外观搬迁已有账本，不改核心人设卡；也不包装宿主权限、沙箱、终端和进程服务。“完全权限”仍由宿主决定。

旧版没有个人归属信息的普通记忆继续保持原有读权，不凭内容猜测它属于哪个人；新会话不能被当成已确认的稳定关系。升级前已经按组织规则共享的旧资料，如需改为私人，应由本人显式删除并按当前关系重新记入。新入口生成的个人记忆和收录记忆都有明确归属。

## 自动阅读与成本

默认开启目录增量收录、轮末辅助阅读和已安装B站插件的自主探索，使用当前真实Lead的模型路由。每轮末最多两批提炼；每个UTC日默认最多4次模型调用（包括选题）、提供资料48000字符，以及1次自主探索尝试。每批提炼最多12000字符和3条草稿。调用前持久预留，失败不退还；计量为资料字符与模型调用准入次数，不是token、总费用或整个会话硬限额。

自主探索要求同一真实Agent仍在宿主活跃注册表，且能看到`bili_humanism_candidates`和`bili_humanism_read`。先经原生工具流水线取最多3个公开候选，辅助模型参考自己的少量近期兴趣选择一个或不选，再经原生流水线取稿。只允许选择实际候选ID；没有任意工具或URL转发，不绕过宿主允许/拒绝/询问策略。暂停、换Agent、切项目、卸载和超时都会停止交付，失败不自动重试；未安装来源插件时跳过探索，目录和会话照常工作。外部取稿失败也不阻止本地材料阅读。该入口只接收最终成功的文字，图片和完整视频理解不在当前自动提炼的覆盖中。

辅助模型没有工具、权限或宿主系统提示，只输出结构受限JSON。引文必须位于实际提供的片段，程序核对出处、版本与覆盖，不认证语义正确。长文按覆盖区间续读，片段反思不能声称完整观看。

没有模型路由时保持待阅读。恢复会话尚未完成本进程的 Lead 身份接续时只等待，不占阅读预算、不记模型失败，也不由后台阅读自行续接或恢复身份；正常宿主会话入口核验后再安排阅读。组件停止、会话/项目变化、暂停、配置变化或来源撤回后，旧辅助结果不能提交，在途模型尝试取消。重启不自动重放未知调用。状态区分阅读中、完成、失败及部分覆盖。

## 成长与能力

吸收必须融入原Mind体系，不建立另一套成长知识库：

| 提炼内容 | 正式保存与调用 |
| --- | --- |
| 兴趣、审美、表达趣味、认识或疑问 | 原偏好类中的Lead人格连续性，保留自省性质 |
| 有意义的真实共同经历 | 原经历记忆，Lead上下文最多装配两条摘要；外部作品不能冒充双方经历 |
| 专业知识与潜在方法 | 原知识记忆，按Lead自治分配的实际岗位进入原专业召回 |
| 经过真实任务试用且满足分享边界的方法 | 原自治能力库，保留适用条件、局限和试用声明 |

`pref-/exp-/know-`条目是正文和生命周期真源；收录区只是处理回执。原生`memory_lifecycle overturn`的更正会在回执中显示，invalid/demote会退出默认召回和后续辅助提炼；来源撤回也会同步裁剪正式记忆。收录区更正通过原记忆服务写新版并退休旧版，拒绝覆盖期间发生的原生更正。原生写入与回执之间中断时，未完成条目不参与召回；重试沿稳定幂等键恢复，不重复调用模型或生成另一份有效正文。已落正式记忆仍保留最小引文证据，不依赖短期轮缓冲一直存在。

兴趣可淡去，也可用新材料重新理解；显式替代使旧记录退出默认使用并保留历史。人侧纠正或停止的记录，模型不能自行覆盖或恢复。共同经历不要求总结道理，也不认证模型有主观感受。

能力候选保留方法、适用条件、局限与岗位，阶段为灵感/待试用/已验证/需修订。标“已验证”需同项目真实已采纳或已结账任务的一次有帮助试用声明，仅证明关联与状态可核对，不证明能力导致改善或可以泛化；无改善、变差和未知同样保留。

来源有效、完成试用且明确跨项目共享给岗位的候选才能发布自治能力库。发布使用稳定ID，支持核对重试，不覆盖其他内容；发布后仍检查来源与候选有效性，撤回或推翻后退出Mind默认能力列表、解析与读取。已进入模型上下文的内容不因此被声称抹除，外部代码不因入库就安装执行。

## 模型动作

三个动作属于原有 `mind` 工具，身份与项目来自真实会话：

- `information_query`：`信息={collection:"status|materials|growth|interests|candidates",id?,query?,offset?,limit?}`。
- `information_read`：`信息={id,hash?,version?,offset?,limit?}`；返回readingId、文字、覆盖和nextOffset。计入阅读预算，不自动产生反思。
- `information_update`：`信息={op,data}`。submit：`{messageIds,title?,note?}`；submit_tool：`{receiptId,title,note?}`；record：`{type,kind?,title,text,sources:[{readingId,quote}],method?,conditions?,limitations?,roles?,expiresAt?,replaces?:[{id,revision}]}`；finish：`{readingIds}`；revise：`{id,revision,reason,text?,state?,stage?,trial?:{task,outcome,detail},expiresAt?}`；distribute：`{id,revision,roles,reason}`（roles为空收回Lead）；publish：`{id,revision}`。

模型不能配置来源、预算、关系或扩大私密边界；自治来源内的专业知识归属由Lead自行处理。新版本需要重新阅读，旧引用不自动升级。审批档位下，正式记忆的创建、更正、分配和旧条目停用均纳入冻结计划，批准前不留下部分写入。

来源工具回执只观察宿主 `tools/result` 正式成功文字，用服务端随机ID绑定实例/会话/项目，内存最多64项、30分钟有效，卸载清空。当前适配 `bili_humanism_read/source/inbox/personality`、`bilibili_subtitles/video`、`bilibiliextract`、`rss_fetch`、`read`、`web_fetch`、`web_search`。不替换任何宿主或第三方方法。文字最多12000字符，仍保留分页、摘要或片段限制。

## 已认证人侧与插件API

三个固定端点都要求宿主Connection认证和同源，缺认证不退回无头通道：

| 端点 | 合同 |
| --- | --- |
| `/plugins/dsh-mind/information` | GET：配置、来源、分页资料/成长/候选、用量和任务；POST：configure/source_save/sources_add/source_remove/scan/revise/forget/purge/share/relationship |
| `/plugins/dsh-mind/information-material` | GET：id/hash/version/offset/limit查看原文；人侧预览不消耗模型阅读预算 |
| `/plugins/dsh-mind/information-deposit` | POST：producer、externalId、title、text、coverage、scope，可附author/url；不主动访问URL |

配置修改带expectedRevision=configRevision，记录修改带revision，旧草稿返回409。投递ID绑定producer、externalId和范围，同文幂等、新文留版。HTTP体最多64KiB，大材料走目录；单文件默认最多1MiB。scope为 `{project:null或项目键,audience:"auto|lead|roles",roles:[],relationship:null或稳定标识}`；auto由Lead决定适用岗位，不能带私密关系，roles用于兼容既有显式上限。

设置页只展示紧凑入口；管理弹窗分“连接目录、收录与沉淀、阅读设置”三栏，目录多选弹窗可在其上打开。关闭不丢草稿，版本冲突保留草稿并要求核对，保存期间不能误关窗口。

`sources_add`接收`{op:"sources_add",expectedRevision,sources:[来源配置,...]}`，一次新增1至64个来源，不接受已有id。全部路径、范围、重复与容量校验通过后才原子保存；任何一项失败不部分连接。目录选择只使用宿主公开的`uiWorkspace.listDirectory/pickDirectory`与桌面窄选择接口，不创建工作区或会话，也不修改宿主服务。

账号评论、私信、点赞等不属于本功能；第三方插件的账号开关与调度仍归其自身。本功能不以收录数、反思数或模型自评证明人格成长与任务收益。

目录发现兼顾现有兴趣的标题词面线索与陌生领域探索，不把词面匹配称为语义理解。全文搜索每批最多检查200份资料，按nextOffset续查，明确已检查范围与命中数。相同规范化快照只在同范围内复用整理状态。readChars按UTF-16代码单元计数。
