# 第六轮：模型用量的只读观察

状态：开发候选已完成离线统一验收，未提交、未部署。上一轮代码已提交推送 `ee2e49a710de259880cf7271708d110ade336e86`；本轮另记后续改动与验证。

## 已实现范围

- 接入已安装宿主公开的 `agent/assistant-stream` 合同，保存开始、usage 快照与结束观察，不调用模型、不存正文、思维、工具参数或错误原文。
- 用服务私有真实 Agent 生命周期区分可重新计数的 attemptId/revision；每次尝试只取最后合法 usage 快照，失败/放弃已报告用量保留，缺结束不补造完成。
- 起始时按有效活动绑定归类单一目标，Lead、会审、多目标与未关联任务保留未归因。后来的进展、终止或新绑定不改写旧观察；该归类不证明请求语义或实际计费归属。
- 新增治理只读 `usage_query`，有界分页、全记录汇总及字段覆盖分母；模型没有写入或伪造用量入口。工作台与看板共用领域读面，成员不取得全项目统计。
- 固定整数强校验，已知 0 与未知分开，缺失 total 不推算；未缓存输入和缓存分桶，推理不再次加入输出。费用及全量 token 为 null，不改变已有准入额度。
- 内存尝试索引与异步写队列有上限，坏帧、未接线、写入失败和溢出明确反馈缺口；采集不会拦截正常模型或工具，关闭观察不改权限。

## 覆盖边界

只覆盖接线之后收到的 live 模型帧，没有导入历史会话或保证中途装载完整，辅助模型请求不完整覆盖。配置路由提示不保证当次请求或远端实际计费路由。committed assistant/message 可包含取消前缀，不能当业务成功；用量未知不补零。

新 Agent 生命周期和真实帧由宿主内存来源识别；本账本不是提供方独立账单，也不证明原会话正文或合法行删除/回滚未发生。只有本地隔离夹具注入，未启动真实 Agent、真实模型请求或更新运行链接目录；真实宿主装载验收、持久对账及费用硬上限仍未完成。

反例保留同 Agent 重复帧、新 Agent 重用旧编号、缓存与推理不叠加、同样本冲突/乱序、缺失与已知 0、累加溢出、严格坏账、失败/放弃/缺结束、项目及目标过滤、绑定变化不改旧归因、正文不落账、失效身份保留未知归因、真实 Lead 卡或当前读权失效时隐藏工作台读面。只读投影不追加审计或用量事实。128 项索引及 1024 项写队列边界使用 stub，业务不会等待采集写入。

冻结前集成和独立测试发现 Lead 适配形状差异：真实 `agentSubject` 带 `roleId:Lead`，观察账本规范形状不接受该字段，导致 Lead 未归因观察漏记。适配器改为白名单提取主体，保留 Lead 当前请求的未知归因；原断言保留并通过定向与完整池。宿主 finish 的 reason 为对象，持久化只保存封闭 kind；不保存错误原文，也不把 committed message 解释为成功。

独立静态核查进一步确认，当前内建 loop 把真实 Agent 闭包带入普通 payload，Cordis 只 trace 顶层参数，不递归替换 `payload.agent`；WeakMap 生命周期有该实现链依据。Cordis 本身没有通用代理缓存，不能把本路径的结论推广到任意服务代理。

完整池仍含坏记忆行等预期故障注入输出。测试总耗时不是本功能的独立性能基准；没有大账本或跨进程压力验收。新记录会严格全量读折叠，长时运行的索引与存储性能优化仍待实测。
