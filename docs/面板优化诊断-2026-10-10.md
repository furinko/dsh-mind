## 三、已定案不许翻烧饼（历批次成果，优化时保持）

- **Batch 8**：介入度是**单值只读**（不许改回 4 个可点 chip——「看着能点」误导）；失联四态四样（`已关闭` 不给绿点）；详情贴格不拉整行。
- **Batch 9（治空位）**：**没数据的格不出现**；值不许是光秃秃 `—`（给「未接入/宿主没给」人话）；审计流**框内滚动 + 框尾「另有 N 条」**（不许静默截断）。⇒ 空态优化（候选①）别开倒车画空壳。
- **取数不挂 `useEffect`**（Batch 7）：裸 `setInterval` 轮询 + 模块级 store（:1362 起），组件只订阅——**任何新数据面都走这条路**，别往 effect 上挂。
- **只读投影**：面板**不给可点控件**（§9）——引导/命令一律「可选中复制的文本」，一键复制按钮属风险项（宿主剪贴板 API 未验证，若做先探针）。
- **样式只用 `--dsw-alias-*` 令牌 + 兜底色**（:565 起）——令牌改名只掉外观不掉功能；新样式同口径。
- **⑮ 强制反对者**（2026-10-10）：**有值才画**（:1826），别名 `dissenter` 的归一化在 :456-492 一带——动 `reviewRow` 时两处一起看。
