# 任务图开节点

**一句话**：写不出判据就不许开节点；派发之后判据冻结。

持续目标先 `goal_query` 核当前结果、限制和下一步，再按需 `goal_create` 登记明确意图的转述；普通问答无需建目标。`goal_link_task` 引用同项目既定任务，不复制或改写判据。来源转述未经人侧核验，不授新权；Lead 只可增加约束，改目标本意、删限制或恢复用户暂停须人侧 `goal_decide`。等待条件解除可用 `goal_progress` 更新下一步，无需重复确认。

目标修订改变后以当前约束推进，不能靠旧任务或正式后继绕过。`goal_complete` 逐条给完成核对及真实采纳证据，复核当前产物内容；任务全部结账不自动代表目标达成。目标摘要省略正文时显式取详情核对，暂停也不能声称在途宿主操作已经停止。

`budget_query id=<目标>` 可查受管准入额度，配置只走人侧 `/mind budget_decide`。它目前只覆盖可归因普通成员文件与成员创建，每次准入占 1，失败及未知结果不退；换实例和后继不清零，token 与费用未知。额度耗尽时报告实际占用与剩余工作，不盲重试或自改上限；合法查询、排障和历史交付仍可继续。没有配置不补零，也不为普通问答额外建目标或要求预算确认。

## 适用岗位

- Lead
- 插件工程
- 记忆整理

## 怎么做

需要正式交付、委派或保留验收证据时使用本规程：Lead 建与派，成员在自己节点内执行。普通问答及范围内的只读调查不必先建立任务；本规程不扩大任何工具或文件权限。

1. **受理先成句**：把需求写成一句可验收的话。写不成句 ⇒ 回到线程要信息，**不开节点**。
2. **判据必填**：节点建立时就要给出**验收标准**，且要能被第三方独立复核。判据空缺即拒建。
3. **标依赖**：写清该节点依赖哪些节点。派发时按精确节点 id 核对已被合法采纳，未采纳不能派发；前置任务有已采纳后继也不自动替原 id 满足依赖。
4. **一岗多人 ＝ 并行分担**：名单即全部事实，**不再写「模式」字段**（已废止，v2 · 2026-10-18）。
   要独立意见走**会话级会审**——不占任务节点、不走派发 / 复核 / 结账。
5. **派发即冻结**：派发事件落账后，**任何改判据的事件都拒绝**。判据要改 ⇒ **开新节点**，旧节点与旧记录保留。
6. **执行只认自己那片**：成员以真实绑定、有效岗位凭证和现行授权执行；任务绑定不等于任意工具权限。通用文件域须在部署上限内于派发时授予，缺省为空。交卷只提交自己节点的产出，不替别人交。
7. **产出物只存引用**：可引用已授权的真实文件、目录或对象版本，**节点只存引用与内容清单**。提交冻结清单，复核与采纳核对当前内容；无法解析的引用不构成合格证据。不把节点当正文仓库。
8. **交卷带证据与结论**：产物引用 ＋ 结论分开写；复核实例据此逐条对判据。
9. **待决项是节点状态**，不是"忘了这件事"：挂起要显式写成节点状态，工作台才投影得出来；
   **待决项的记录不可静默丢弃**，清队列要入账。
10. **打回计数记在节点上**：同一节点打回 ≥2 次 ⇒ **升级主权者**；换人重做，计数照样累加。
11. **明确终止旧工作**：Lead 或主权者用 `task_close id=<旧任务> 原因=...` 结束未完成任务的组织授权，原答案、署名和证据保留。终止不等于采纳、宿主停止或在途工具已取消；已采纳、已结账和旧独立会审不能借此改状态。
12. **正式后继不改旧账**：用 `task_successor id=<已终止源> 负责人=<新负责人> 原因=...` 建立唯一可追溯后继。它复制原判据、依赖与显式复核对象并冻结判据，必须重新绑定、授文件范围和派发；不复制旧答案、票、免审和授权。累计打回及前序待决/升级线索保留，不能借新 id 清零或冒称已裁决。
13. **重复请求只认回执**：同规范已提交的终止或后继请求只读认回，不再做一遍，也不为认回另开审批。已经消费的旧批准引用不能重放；发生部分提交先核对真源，不盲重试。

## 判据

- **状态权威在任务图**：工作台、口述、聊天记录都不是状态来源；对不上以任务图为准。
- **可重算**：节点状态能从事件流重算；日志缺失或损坏要显式报错，不许静默当"已完成"。

## 不做什么

- 不替策略引擎做调度决策：**判权限**是判定点的事，**派谁**才是 Lead 的事。
- 不做讨论区：节点不放聊天，讨论走消息总线线程。
