# 记忆写入

**一句话**：记忆**只追加**；写入必须带「谁记的 ＋ 怎么知道的」。

<!-- authority: 自治 -->
## 适用岗位

- 文档整理
- 记忆整理

## 怎么做

写入与维护都照这份走：文档整理负责条目，记忆整理负责条目状态。

1. **先分四类，再落笔**：知识 / 经历 / 偏好 / 作答。**能力不在这里**——技能与规程进能力库，不进记忆服务。
2. **写入必带来源**：**谁记的 ＋ 怎么知道的**。来源缺失即拒写；"我记得"不是来源。
3. **按归属选命名空间**：

   | 类 | 归属 | 命名空间 |
   |---|---|---|
   | **知识** | 岗位 ＋ 项目**双标签** | 跨项目（岗位）/ 本项目 |
   | **经历** | 组织账本 | 只增 |
   | **偏好** | 部署 | **永不外流** |
   | **作答** | 实例 | 私有区内部，任务结束归档 |

4. **知识标签规则**：**项目标签恒打**（它产生于某个项目）；**岗位标签默认不打**，由 **Lead 判定"这条跨项目可复用"后追加**。
5. **写入时校验正文结构**：必填段缺失、来源缺失 ⇒ **拒写**。事后修补会违反"不许改写只能追加"，所以这是**唯一时机**。
6. **不许改写，只能追加**：

   | 情形 | 处置 |
   |---|---|
   | 经历 | 只增，不改 |
   | 错误 / 过期 | **追加 `invalid` 状态** |
   | 冷 | **追加降权状态**，不删 |
   | 被推翻 | **追加一条双份留痕**（原条 ＋ 新条都指得清） |
   | **物理删除** | 仅限：敏感数据、主权者明确要求 |

7. **归档作答，并守读权限**：主权者 / Lead / 复核者可读；**成员不可读**；自动检索**不进默认检索面**，可显式检索。
8. **检索按需拉**：上下文只带本轮线程消息与当前项目记忆；**全量历史、其他线程、其他项目一律不进**。

## 判据

- **单源**：一条事实只有一处出处；发现两处，判断哪一处是源，另一处改成引用。
- **可追溯**：任何条目都能回答"谁在什么时候、凭什么知道的"。
- **报「0 命中」必须连口径一起报**：搜索面 / 查询词 / 范围。

## 不做什么

- 不装能力（那是能力库）。
- 不决定注入什么（注入面是调用方按需拉）。
- 不上数据库：账本式 `.jsonl` ＋ 可重算的索引足够。
