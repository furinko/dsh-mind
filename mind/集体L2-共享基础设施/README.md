# 共享基础设施（出厂侧）

> 这一页只说三件事：每个子目录装什么、哪一份是**程序**、哪一份是**数据**。
> 纪律：**目录负责「找得到」，标签负责「谁能改」**——判定授权只读标签，不读路径。

<!-- authority: 自治 -->
## 出厂侧装【程序】

| 子目录 | 装什么 | 备注 |
|---|---|---|
| 策略引擎/ | 判定程序 | 启动时加载宪章 / 法律 / 编制；**加载失败 fail-closed** |
| 角色注册表/ | 重建索引的程序 | 索引**不是真源**；真源 ＝ 岗位卡 ＋ 身份档案 |
| 共享工作台/ | 投影程序 | **无存储**：能从任务图 ＋ 日志重算 |
| 任务图/ | 事件流的读写程序 | 数据落私有区；**判据必填、派发后冻结** |
| 消息总线/ | 线程读写程序 | 消息 `authority ＝ 只增`；**历史不入上下文** |
| 能力库/ | 出厂能力卡（怎么做） | 只放**技能与规程**，不放知识 / 经历 / 偏好 |
| 记忆服务/ | 写入 · 检索 · 固化 · 失效 · 裁决的程序 | 数据落私有区；**不许改写只能追加** |
| 审计日志/ | 追加与链自检程序 | **只增**，不承担回滚、不做状态 |
| defaults/ | 出厂默认值与探针声明 | 见下 |

## 私有侧装【数据】

任务图/<项目>/ · 消息总线/<项目>/*.jsonl · 记忆服务/（跨项目 ＋ 各项目）· 审计日志/audit-YYYY-MM.jsonl ·
角色注册表索引 · 共享工作台（无文件）· 自治能力库 · 版本历史 · 升级/（基线戳 ＋ 挂起的 diff）· 身份档案。

**判据**：**随产品更新的是程序；跑出来的、可回滚的是数据。**
拿不准时问一句：**重装产品之后，这条内容还在吗？** 在 ⇒ 数据，落私有区。

## defaults/

| 文件 | 内容 | 谁能定 |
|---|---|---|
| 介入度.json | 四档之一（默认零参与）＋ 响应期限小时 | 主权者 |
| 响应期限.json | 超期即系统自动标记失联 | 主权者 |
| 工具总范围.json | 空数组 ＝ 不额外收窄 | **主权者** |
| 安全类探针.json | 封闭清单的探针声明 | **主权者声明，出厂作者实现** |

## 能力库：双区各一份

出厂侧这份是**出厂能力库**（随产品更新，不就地改）；组织自己长出来的技能落私有区的**自治能力库**。
**同名不合并**：两条都返回并标注来源，默认用自治版，冲突时并列给 Lead 判。
岗位卡只在 `个体L2` 里**引用 id**，不内嵌正文——一项能力被多岗位共用时只改一处（**单源**）。
