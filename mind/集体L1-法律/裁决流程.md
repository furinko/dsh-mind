# 裁决流程

> 出厂默认文本，主权者可覆盖。本文规定**复核与裁决怎么收口**：三态、打回、升级、会审边界。
> 段标签：复核规范段 ＝ **法律**；会审作业细则段 ＝ **自治**。

<!-- authority: 法律 -->
## 复核三态

复核只有一个出口，三个取值：

| 态 | 含义 | 后果 |
|---|---|---|
| **过** | 判据逐条对得上，反例面已给出且不成立 | 可采纳 |
| **不过** | 判据对不上，或反例面成立 | 打回，节点打回计数 ＋1 |
| **未验** | 复核员**在权限内无法完成验证**：拿不到读数 / 证据不足 / 超时 | **不计打回**，升级补材料 |

**复核输出必须带**：三态 ＋ **分歧清单**（与交卷方看法不同的每一条）＋ **反例面**（能推翻结论的具体情形；没有就明确写「未找到」）。

**谁复核**：任务到「已交卷」后，**Lead 按任务用 `member_spawn` 起一个复核实例**（岗位 `复核员`）——机制把派发时冻结的判据附给实例，Lead 的任务书只是补充说明。**没有常驻复核实例、没有排队**。
**冲突排除**：执行者 / 交卷人 / 负责人 / 同会话者**不得复核本任务**——由机制判，不由人自觉；**复核署名必须是在册在岗的复核员实例**（不可自报、不可指向空气）。
**硬闸**：没有「过」不得采纳；「未验」也不得采纳。Lead 可**记录不同意**，**不得修改复核结论**；采纳必须引用复核结论。
**已知缺口（主权者认可）**：Lead 拖着不复核 ⇒ 任务停在待复核。这是**停滞**，不会产生错误采纳；机制里不造自动复核来兜它。

<!-- authority: 法律 -->
## 未验：最容易被将就的一态

| 问题 | 答案 |
|---|---|
| 算不算通过 | **不算。未验 ≠ 通过。** |
| 计不计打回 | **不计**——它不是执行方的错，是验证条件不足 |
| 谁接手 | **升级 Lead 补材料**（补读数、补证据、补权限） |
| 补不了怎么办 | **升级主权者**，进待决项，**记录不丢** |
| 能不能一直挂着 | 不能：待决项是节点状态，工作台把它投影出来，挂而不报 ＝ 留痕缺失 |

**未验不得被当成「差不多过了」。** 把未验写成过，是裁决层最贵的错误。

## 结论的不可修改性

- **复核结论不经 Lead 修改**：Lead 可以**记录不同意**，**不能改结论**。
- 记录不同意要落在节点上：理由是给后来人看的，不是给这次翻案的。
- **同一节点打回 ≥2 次 ⇒ 升级主权者**。次数记在**任务节点**上，不记在人头上；换人重做也照样累加。
- 升级后由主权者裁决：可采纳、可重定判据、可撤节点。**重定判据 ＝ 新节点**，旧节点的记录保留。

## 会审（会话级独立功能）

会审**不占任务节点、不走派发 / 复核 / 结账**——它是会话里的咨询工具：抛问题 → N 个独立实例作答 → 交齐解锁 → 收敛结论。想干活，拿结论往台账正常登活。

- **解锁** ＝ 本场会审**按人交齐** → 揭名（仅 Lead 触发）。边界写死，不看人情、不看进度。
- **提交后解锁（含盲评）**：未交齐只见盲标，交齐揭名；盲评不单列成一项。
- **多人派活只剩并行分担一种**：独立会审退出任务图后，任务节点不再写「模式」字段（已废止）；历史事件里的模式**只读不迁移**。
- **Lead 不首发**：征求意见时 Lead 最后表态。
- **讨论段默认不开**：Lead 显式开启；预算上限照旧（轮 2 / 人 8 / 每轮 24 条 / 每人 4000 字），发起时冻结快照。
- **零分歧报警**：判据 ＝ **结论层一致且无人给出反例面**（不是文本一致）。命中即记「**会审零分歧异常**」并入存档——**纯信号**，留给人看。
- **强制反对者已砍**：轻量咨询不值一次实例调用；分歧不足由零分歧报警补位。
- **旧数据只读**：任务图里历史的会审 / 讨论事件原地只读，不迁移、不进新会审面。

## 拒绝必须带可执行理由

任何拒绝——策略引擎的、复核的、仲裁的——都要说清两件事：

1. **哪条规则**（指回条款或对象 id）；
2. **改它要什么授权**（谁点头、走哪一档门槛）。

只说「不行」的拒绝 ＝ 无效拒绝，收件方有权要求补齐。
拒绝本身**无条件入账**，理由与依据一并落账。

## 会审作业细则

- **先看判据再看答案**：判据冻结后，复核按判据逐条走；判据有歧义时按**未验**处理，不按理解放宽。
- **分歧清单只增**：讨论阶段新增的分歧另起一条，不改已交的分歧清单。
- **反例面要具体**：写「某输入 + 某条件下结论不成立」，不写「可能有风险」。
- **裁决留痕五件齐**：谁提的 / 凭什么 / 谁复核 / 结果 / 可回滚点——缺一件即视为未结案。
