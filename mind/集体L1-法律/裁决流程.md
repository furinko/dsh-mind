# 裁决流程

> 出厂默认文本，主权者可覆盖。本文规定**复核与裁决怎么收口**：三态、打回、升级、会审边界。
> 段标签：复核规范段 ＝ **法律**；会审作业细则段 ＝ **自治**。

<!-- authority: 法律 -->
## 复核三态

复核只有一个出口，三个取值：

| 态 | 含义 | 后果 |
|---|---|---|
| **过** | 判据逐条对得上，反例面已给出且不成立 | 可采纳 |
| **不过** | 判据对不上，或反例面成立 | 打回，节点打回计数 ＋1 |
| **未验** | 复核者**在权限内无法完成验证**：拿不到读数 / 证据不足 / 超时 | **不计打回**，升级补材料 |

**复核输出必须带**：三态 ＋ **分歧清单**（与交卷方看法不同的每一条）＋ **反例面**（能推翻结论的具体情形；没有就明确写「未找到」）。

**谁复核**：由**主权者确认**的复核者（Lead 可提名）。复核者不参与提案，也不参与被验任务的执行。

<!-- authority: 法律 -->
## 未验：最容易被将就的一态

| 问题 | 答案 |
|---|---|
| 算不算通过 | **不算。未验 ≠ 通过。** |
| 计不计打回 | **不计**——它不是执行方的错，是验证条件不足 |
| 谁接手 | **升级 Lead 补材料**（补读数、补证据、补权限） |
| 补不了怎么办 | **升级主权者**，进待决项，**记录不丢** |
| 能不能一直挂着 | 不能：待决项是节点状态，工作台把它投影出来，挂而不报 ＝ 留痕缺失 |

**未验不得被当成「差不多过了」。** 把未验写成过，是裁决层最贵的错误。

<!-- authority: 法律 -->
## 结论的不可修改性

- **复核结论不经 Lead 修改**：Lead 可以**记录不同意**，**不能改结论**。
- 记录不同意要落在节点上：理由是给后来人看的，不是给这次翻案的。
- **同一节点打回 ≥2 次 ⇒ 升级主权者**。次数记在**任务节点**上，不记在人头上；换人重做也照样累加。
- 升级后由主权者裁决：可采纳、可重定判据、可撤节点。**重定判据 ＝ 新节点**，旧节点的记录保留。

## 会审解锁边界

- **会审解锁** ＝ 任务图报「**全员已交**」→ 消息总线解锁并广播。边界写死，不看人情、不看进度。
- **提交后解锁**：全员交卷后才亮出彼此答案。
- **一岗多人必须显式声明模式**：

| | 并行分担 | 独立会审 |
|---|---|---|
| 互相可见 | 能 | **交卷前不能** |
| 共享 | 中间结果 | **只共享岗位知识与能力** |
| 产出 | 合起来的成果 | N 份独立答案 ＋ **分歧清单** |

- **Lead 不首发**：征求意见时 Lead 最后表态。
- **强制反对者**：**系统随机指定一名未参与成员**，且**不重复**。
- **盲评**：第一轮只显示「成员 A / B / C」，揭名在讨论阶段。
- **零分歧报警**：判据 ＝ **结论层一致且无人给出反例面**（不是文本一致）。命中即记「**会审零分歧异常**」并**触发人工抽检**。

<!-- authority: 法律 -->
## 拒绝必须带可执行理由

任何拒绝——策略引擎的、复核的、仲裁的——都要说清两件事：

1. **哪条规则**（指回条款或对象 id）；
2. **改它要什么授权**（谁点头、走哪一档门槛）。

只说「不行」的拒绝 ＝ 无效拒绝，收件方有权要求补齐。
拒绝本身**无条件入账**，理由与依据一并落账。

<!-- authority: 自治 -->
## 会审作业细则

- **先看判据再看答案**：判据冻结后，复核按判据逐条走；判据有歧义时按**未验**处理，不按理解放宽。
- **分歧清单只增**：讨论阶段新增的分歧另起一条，不改已交的分歧清单。
- **反例面要具体**：写「某输入 + 某条件下结论不成立」，不写「可能有风险」。
- **抽检不预告**：人工抽检由系统标记触发，被抽到的一方不参与抽检安排。
- **裁决留痕五件齐**：谁提的 / 凭什么 / 谁复核 / 结果 / 可回滚点——缺一件即视为未结案。
